# Ish topdim — to'liq audit (2026-10-31)

Manba: egasining "Complete product audit, redesign & business transformation" topshirig'i. Audit **kod o'qib** va **lokal
stendda ishga tushirib** (skrinshotlar: 320–1440 px) qilindi. Production bazasiga kirish yo'q — production sozlamalari
(masalan, pullik e'lon rejimi) kodning standart qiymatlari bo'yicha baholandi.

Umumiy xulosa: loyiha **yetuk** — qidiruv, vakansiya sahifasi, ariza, statuslar, chat, ish beruvchi paneli, moderatsiya,
tasdiqlash, shikoyatlar, admin (MFA, ruxsatlar, audit), Payme/Click, RLS — hammasi bor va testlangan (E2E 218, SQL testlar).
Qayta yozish kerak emas. Asosiy muammolar: **bitta buzilgan oqim**, **ikki xil takror oqim** (qidiruv va e'lon berish),
**yo'qolayotgan analitika**, **SEO kamchiliklari**, va spetsifikatsiyadagi bir nechta **yetishmayotgan bo'lak**.

Ustuvorlik: **K** — kritik, **Y** — yuqori, **O** — o'rta, **P** — past. Holat ustuni: **✅ shu PR da tuzatildi**,
**⏳ keyingi bosqich**, **❓ egasining qarori kerak**.

## 9. Production'ga chiqarish tartibi

1. **Avval bazaga** 0069 → 0070 → 0071 → 0072 → 0073 migratsiyalarini qo'llang (`npx supabase db push` yoki Supabase → SQL Editor,
   har biri alohida, tartib bilan). Kod migratsiyasiz ham buzilmaydi (yopilgan sahifa — 404, yangi filtrlar — e'tiborsiz,
   TOP — xato xabari, "Mening dunyom" (0073) — ko'rsatilmaydi), faqat **/companies** "Ro'yxat vaqtincha ochilmadi" ko'rsatadi.
2. Tekshirish (SQL Editor): `select to_regprocedure('public.vacancy_public_stub(text)') is not null as a,
   to_regprocedure('public.public_companies(text, uuid, int, int)') is not null as b,
   to_regprocedure('public.admin_set_vacancy_featured(uuid, int)') is not null as c,
   to_regprocedure('public.set_my_interests(uuid[])') is not null as d;` — hammasi `true`.
3. Keyin kodni `main` ga — Vercel o'zi chiqaradi.
4. Ixtiyoriy: Vercel env `SOCIAL_*_URL` (footer); admin → «Pullik e'lonlar» qarori (§1, 3-qator).
